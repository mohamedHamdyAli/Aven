High Impact Features

Immediate uplift on traffic capture, checkout trust, and product discoverability

💬 WhatsApp Floating Button Done

Fixed bottom-right button opens WhatsApp with a pre-filled message. Fully configurable from admin — phone number, message text, and on/off toggle.

Config: general.design.whatsapp_button
File: components/layouts/index.blade.php
📧 Newsletter Popup Done

Timed popup (configurable delay) captures visitor email. Uses sessionStorage to avoid repeat shows. Checks localStorage "already subscribed" flag. AJAX submission to existing subscribers table.

Config: general.design.newsletter_popup
Guards: Session + localStorage dedup
🔔 Back in Stock Notification Done

When a product's stock is zero, the Add-to-Cart area is replaced by a "Notify Me" form. Visitor enters their email (or phone). Stored in new stock_notifications table, ready for dispatch when restocked.

Table: stock_notifications
Route: POST /stock-notify
File: products/view.blade.php
🛡️ Checkout Trust Badges Done

Four SVG trust badges injected into both the cart summary sidebar and the onepage checkout summary: Secure Checkout, Easy Returns, Quality Guaranteed, Fast Delivery.

Files: checkout/cart/summary.blade.php
checkout/onepage/summary.blade.php
⚡ Buy Now Button Default-On

Previously required explicit admin activation (null = off). Changed condition to !== '0' so it shows by default on all product pages without any config change needed.

Config: catalog.products.storefront.buy_now_button_display
🔍 Schema.org Rich Snippets Default-On

Product JSON-LD injected into every product page for Google rich search results (star ratings, price, availability). Same null → default-on fix as Buy Now.

Config: catalog.rich_snippets.products.enable
File: products/view.blade.php
🚪 Exit Intent Popup Done

Detects when the user's mouse moves toward the top browser bar (intent to leave). Shows a last-chance offer modal with a configurable discount message. Shown once per session via sessionStorage guard. Injected into the global shop layout.

Trigger: mouseleave on document (clientY < 10)
Guard: sessionStorage['exit-shown']
File: components/layouts/index.blade.php

Medium Impact Features — Part 2

Customer retention, referrals, and bulk marketing tools

⭐ Loyalty Points System New System

Full earn-and-redeem loyalty points program. Customers earn points on every order and can redeem them directly in the cart for an instant discount.

Earn rate: Configurable (e.g. 1 pt per 10 EGP)
Redeem rate: Configurable (e.g. 1 pt = 0.10 EGP)
Min redeem: Configurable (default 50 pts)
Mechanism: Auto-generates CartRule coupon LP-*
Cart widget: Shows balance + Redeem button
Account page: /customer/account/loyalty
New tables: customer_loyalty_points
customer_loyalty_transactions
loyalty_redemptions
Admin config: Configure → General → Loyalty Points → Settings
🔗 Referral Program New System

Each customer gets a unique 8-character referral code. When a referred friend registers and places their first order, the referrer automatically receives a coupon reward.

Share via: WhatsApp + Facebook + Copy link
Reward: Auto-generated REF-* coupon
Table: customer_referrals
Account: /customer/account/referral
Admin config: Configure → General → Referral Program
📱 Bulk Coupon by Phone New Feature

Admin can assign unique random coupon codes to customers via phone numbers — upload a CSV or enter phones manually. Each coupon is locked to its assigned phone only. Admin downloads result CSV and system sends each coupon via WhatsApp.

Route: admin/marketing/promotions/coupon-assignments
Table: cart_rule_coupon_assignments
Validation: Customer phone must match assignment

When the main ATC button scrolls out of view, a sticky bar slides up from the bottom with product name, price, and a second ATC button. Uses IntersectionObserver.

Trigger: IntersectionObserver on main ATC button

Displays a live countdown timer on product pages when a sale is active. Timer persists across page loads via localStorage. Resets itself when it reaches zero.

Config: general.design.countdown_timer
Storage: localStorage['aven_ct']

Full multi-channel abandoned cart recovery system. Sends recovery messages via Email, WhatsApp, and Facebook Messenger. Up to 3 configurable attempts with delays.

Channels: Email + WhatsApp Cloud API + Messenger

Activation Checklist (Required After Deployment)

1. Google Analytics 4

Admin → Configure → General → Content → Google Analytics → enter your GA4 Measurement ID (G-XXXXXXXXXX)

2. WhatsApp Floating Button

Admin → Configure → General → Design → WhatsApp Button → enable + enter phone number in international format (e.g. +201XXXXXXXXX)

3. Loyalty Points

Admin → Configure → General → Loyalty Points → enable → set earn rate (e.g. 10 = 1 pt per 10 EGP), redeem rate (e.g. 0.10), minimum (e.g. 50)

4. Referral Program

Admin → Configure → General → Referral Program → enable → set reward type (fixed/percent) and amount

5. Social Login

Create Google OAuth App at console.cloud.google.com and Facebook App at developers.facebook.com → enter Client ID + Secret in Admin → Configure → Customers → Settings → Social Login

6. Abandoned Cart WhatsApp

Admin → Configure → Sales → Abandoned Cart → Channels → enable WhatsApp → enter Cloud API token and Phone ID from Meta Business Suite
