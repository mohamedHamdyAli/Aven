Abandoned Cart Recovery & Fraud Prevention — Test Guide

Bagisto 2.4.x  |  Branch: 2.4  |  Date: 2026-05-08

1. Prerequisites — Run Once Before Testing

composer dump-autoload
php artisan migrate
php artisan optimize:clear
php artisan serve                   # Terminal 1
php artisan queue:work              # Terminal 2  (processes email/WhatsApp jobs)

Verify the new DB columns exist:

php artisan tinker
>>> Schema::hasColumn('cart', 'last_activity_at')   // true
>>> Schema::hasColumn('cart', 'notification_token') // true
>>> Schema::hasTable('abandoned_cart_notifications') // true

2. Admin Configuration

Go to http://localhost:8000/admin/configuration → click Sales
Click Abandoned Cart Recovery
Set values for testing:

3. Email Setup (Log Driver — No Real SMTP Needed)

In .env, set:

MAIL_MAILER=log
php artisan optimize:clear

All emails will now be written to storage/logs/laravel.log instead of being sent.

4. Test Scenario A — Authenticated Customer Abandons Cart

Log in as a customer on the shop front.
Add 1–2 products to the cart but do NOT checkout.
Verify the cart got a token: 
php artisan tinker
>>> DB::table('cart')->where('is_active',1)->latest()->first(['id','customer_email','notification_token','last_activity_at'])
CHECK notification_token should be a 40-char string, last_activity_at should be recent.
Wait 1 minute (or set system time forward), then run dry-run: 
php artisan abandoned-cart:process --dry-run
CHECK Output should list the cart as eligible for attempt #1.
Run the real command: 
php artisan abandoned-cart:process
Check the queue job was dispatched and processed: 
php artisan tinker
>>> DB::table('abandoned_cart_notifications')->latest()->first()
PASS if status = 'sent' and channel = 'email'.
Check the email content in the log: 
grep -A 30 "abandoned" storage/logs/laravel.log | tail -40
CHECK Should contain cart items, total, and recovery link.

5. Test Scenario B — Guest Cart Recovery via Cookie

Open a private/incognito browser window.
Browse the shop and add items to cart.
Go to checkout step 1 and enter an email address — this populates cart.customer_email.
Close the browser window without finishing checkout.
Check the cookie was set: 
php artisan tinker
>>> DB::table('cart')->whereNotNull('notification_token')->where('is_guest',1)->latest()->first(['id','customer_email','notification_token'])
Reopen the browser and visit the shop homepage. The cookie bagisto_cart_recovery should restore the cart. Check the cart icon shows items.
Run the recovery command and extract the signed link from the log: 
php artisan abandoned-cart:process
grep "recover" storage/logs/laravel.log | tail -5
Visit the recovery link from the log in the browser.
PASS if redirected to cart page with a success flash message.

8. Test Scenario E — Fraud Detection

E1 — Disposable Email (score +25)

php artisan tinker
>>> $service = app(\Webkul\AbandonedCart\Services\FraudScoringService::class);
>>> $cart = (object)['customer_email'=>'test@mailinator.com','base_grand_total'=>100,'id'=>999];
>>> echo $service->score($cart);   // Expected: 25+

E2 — Multiple Disposable Signals (score ≥ 60 → auto-flag)

>>> $cart2 = (object)['customer_email'=>'hacker@yopmail.com','base_grand_total'=>5000,'id'=>998];
>>> echo $service->score($cart2);  // Expected: 30+

E3 — Order Gets fraud Status

Place an order from an account whose email is in the disposable domain list. Check:

>>> DB::table('orders')->latest()->first(['id','status','customer_email'])
// status should be 'fraud' if score ≥ 60
SignalPointsHow to Trigger
Disposable email+25Use @mailinator.com
5+ orders same email/60 min+20Place 5 orders with same email
5+ carts same IP/60 min+15Create 5 carts from same IP
Billing country ≠ IP country+10Set billing country to different country + use CF-IPCountry header
Cart value > 3× avg order+10Large cart for customer with small order history
2+ failed payment attempts+152 pending_payment orders on same cart

10. Test Scenario G — Retry Logic (Max Attempts)

# Run the command 3 times (with 0-hour delays configured)
php artisan abandoned-cart:process
php artisan abandoned-cart:process
php artisan abandoned-cart:process

# Check notification count
php artisan tinker
>>> DB::table('cart')->where('is_active',1)->latest()->first(['id','notification_count','recovery_status'])
# notification_count should be 3, recovery_status = 'recovering'

# Run once more — should NOT dispatch new job (max reached)
php artisan abandoned-cart:process
>>> DB::table('abandoned_cart_notifications')->where('cart_id', $cartId)->count()
